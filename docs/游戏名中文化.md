> 本文摘自本项目的开发记录，保留当时的分析过程与结论。
> 文中出现的工作区路径（`tools/`、`dist/`、`D:/…`）是开发时的目录，
> 在本仓库中的对应位置请以根目录 README 的目录表为准。

## GameCube 游戏名中文化（2026-11-09）

`sdb:/root/game/GameCube/` 下 64 个文件里的 56 个英文文件名已全部改为中文
（55 个游戏 + 1 个 `swiss document.txt`），另外 8 个原本就是中文名，保持不动。
只改文件名，不改内容、不改扩展名、不跨目录移动。完整对照表见
`dist/GameCube_中文译名表.md`，逐项记录见 `dist/GameCube_改名记录.json`。

### 工具

```bash
python tools/rename_games_cn.py --dry-run          # 校验映射并生成译名表
python tools/rename_games_cn.py --apply --recent  # 执行改名并同步 recent.ini
python tools/rename_games_cn.py --verify          # 复核目录
python tools/rename_games_cn.py --rollback        # 一键还原（需先解锁，见下）
```

译名表写在脚本顶部的 `MAP` 里，改完重跑 `--apply` 即可；已完成的项会自动跳过，
所以网络中断后可以断点续做。`--dry-run` 会检查源是否存在、目标是否被占用、
有无重名、扩展名是否保持、FAT 非法字符，以及固件 1024 字节请求头上限。

### 命名约定

- 保留原扩展名（`.nkit.iso` / `.iso` / `.gcm`），Swiss 靠它识别格式
- 去掉 `(USA)` / `(En,Ja)` / `(Rev 1)` 等英文区域语言版本标记
- 多光盘加 `（第1张）` / `（第2张）`；与已有中文名同游戏时补中文限定，
  例如 `生化危机4（美版 第1张）` 区别于原有的 `生化危机4（disk1）.iso`
- 国际通用专名保留写法：Game Boy、Intellivision、SNK、DX、3D、Swiss
- 长名字在 Swiss 列表里会被截断，但 `/state` 与 `/ls` 里是完整名

### FR_LOCKED(16)：改名前的解锁步骤（重要）

Swiss 的文件浏览器扫描**当前目录**时会持有目录内所有文件的 FatFs 句柄
（为了读 ISO 头与封面）。此时对该目录内任何文件执行 `/rename` 都返回
`FR_LOCKED(16)`；实测根目录与其他目录改名完全正常，说明不是全局锁表耗尽。
`/pad` 注入 `B` / `Z` / `START` 都无法让 `/state` 的 `path` 离开该目录。

可靠解法是让 Swiss **启动时停在别的目录**：

1. 备份 `sdb:/swiss/settings/recent.ini`，把指向该目录的 `Recent_*` 临时改成
   `sdb:/boot.dol` 并上传；
2. wiiload 推送正式 `swiss.dol` 重启（等待约 12-15 s 的真实断连窗口，
   不要被旧 httpd 实例的快速应答骗过），确认 `/state path=sdb:/`；
3. 此时目录未被扫描，`/rename` 可用，跑 `--apply --recent`；
4. 工具把 `recent.ini` 的 3 条路径迁移为中文名并回读校验；
5. 再 wiiload 重启一次，Swiss 跳回 `sdb:/root/game/GameCube` 并停在中文名上。

以后要调整个别译名或执行 `--rollback`，都需要先重复第 1-2 步解锁。

### 不受改名影响的部分

`swiss/settings/game/*.ini`（按 GameID）、`swiss/patches/game/*.bin`（按镜像哈希）、
`swiss/saves/`（记忆卡 raw）、`swiss/cheats/` 都不依赖文件名，无需迁移；
`apploader.img` / `IPL.dol` / `global.ini` 也没有改动。唯一保存完整路径的是
`recent.ini`，已同步。

### 实机验证

56/56 改名成功，`VERIFY: PASS`（64 个文件、0 缺失、0 英文残留、大小一一对应）；
`recent.ini` 3 条路径迁移后回读一致；重启后 `/state` 的 `selname` 为
`Intellivision 经典游戏合集.nkit.iso`，抓屏确认中文名无乱码、无方块字，
顶部 `40°C` 与日期同行、封面与区旗正常。当前使用 Swiss 默认背景（用户自行还原），
本次操作未改动背景设置。
