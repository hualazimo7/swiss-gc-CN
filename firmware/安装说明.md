# Swiss 简体中文版（上游 commit 62a8b9a2 / revision 2154）

GameCube 自制程序加载器 [Swiss](https://github.com/emukidid/swiss-gc) 的简体中文构建。
基于上游 **master commit 62a8b9a2**（2026-11-05，界面显示 revision 2154；比官方最新发布 v0.6r2119 新 35 个提交），界面文本、设置项、帮助说明、错误提示已全部中文化，
并支持在 SD 卡上直接使用中文文件名。

---

## 一、安装

包里有两个 DOL，**放 SD 卡的是 `swiss.dol`**，别用错：

| 文件 | 大小 | 用途 |
|---|---|---|
| **`swiss.dol`** | 约 1.0 MB | **自解压镜像**。SD 卡启动、ISO、CubiBoot / PicoBoot / GCLoader / WODE 全部用它 |
| `swiss-wiiload.dol` | 约 3.2 MB | 原始构建，**仅**用于 wiiload 推送到一台已在运行的 Swiss |

原因：原始构建链接在 `0x80003100`，这是 IPL 类加载器（CubiBoot、PicoBoot）自己占用的
地址区间；加载它会把加载器本身覆盖掉，表现就是**选完文件即黑屏**。官方发布版用的是
自解压格式——stub 放在加载器内存之上，运行时把真正的程序解压到 `0x80003100`。
本包的 `swiss.dol` 就是按同样方式打包的。

### 方式 A：SD 卡（CubiBoot / PicoBoot / 光驱替代设备）

1. 把 **`swiss.dol`** 复制到 SD 卡根目录
   - CubiBoot：在菜单里直接选它
   - PicoBoot：改名为 `ipl.dol`（这是 PicoBoot 的默认文件名，除非你改过）
2. SD 卡插入记忆卡槽 B（或你的适配器对应插槽）
3. 开机

**保留一个能用的备份**：升级前把旧的 DOL 改名留一份（例如 `swiss-old.dol`）。
若新版本黑屏，换回旧文件即可恢复。

### 方式 B：网络推送（已有一台能跑 Swiss 的机器 + 宽带网卡）

```bash
python tools/wiiload.py 192.168.1.2 swiss-wiiload.dol
```

⚠️ 推送请用 `swiss-wiiload.dol`。推送后 Swiss 会重启并运行新程序，SD 卡上的文件不受影响。
若推送中断，主机不会卡死（内部有 10 秒接收超时），重新推送即可。

### 方式 C：光盘镜像

用 `swiss.dol` 自行制作：

```bash
mkisofs -R -J -G bootheader.hdr -no-emul-boot -eltorito-platform PPC -b swiss.dol -o swiss.iso swiss.dol
```

`bootheader.hdr` 取自上游 `buildtools/iso/`（本包未附带）。镜像里的启动文件必须是
`swiss.dol`（自解压版）。

### 黑屏排查

| 现象 | 原因 |
|---|---|
| 从加载器选文件后立刻黑屏 | 用了 `swiss-wiiload.dol`（原始构建），换成 `swiss.dol` |
| 卡在加载器菜单、选不动 | 文件名或分区问题，不是本包的事 |
| 进去后花屏 / 黑屏但网络有响应 | 视频模式问题，试试在另一台机器上改成 480i |

## 二、中文文件名

SD 卡上的文件可以直接用中文命名，例如：

```
/games/塞尔达传说.iso
/games/马力欧赛车.gcm
/apps/中文测试.dol
```

支持范围：**GB2312 一级字库（3755 个常用汉字）** + 界面用字，共 3769 字。

- `.dol` / `.iso` / `.gcm` 三种格式均已验证
- **生僻字不显示**：GB2312 二级字库（约 3000 字）和 GBK 扩展字不在字模内，
  这些字会画不出来。命名时避开生僻字即可
- 已被 nkit 数据库识别的游戏显示的是**数据库里的游戏名**，不是文件名；
  只有未识别的文件（自制程序、未知镜像）才直接显示文件名。这是 Swiss 原有行为

## 四、已知限制

1. **设置项取值保留英文**：`On / Off / Yes / No / Standard / Fullwidth` 等。
   这些字符串同时用于 `swiss.ini` 的写入与解析，翻译会让旧配置全部读不出来、
   相关设置回落到默认值。已加自动化检查拦截这类改动。
2. **顶部标题栏保留英文**：`for GameCube` / `version 0.6` / `commit: … · revision: …`。
   这一行还要放 CPU 温度与右对齐的日期时间（日期串实测 277px），中文副标题更宽会直接
   压上去。温度按要求缩小到 0.45 后与其它元素共存，不再绘制在日期上方。
3. **设置页是半透明覆盖层**：会透出下层文件列表，标题栏会看到两层时间戳叠影。
   英文原版同样如此。
4. **生僻字不显示**：只覆盖 GB2312 一级字库（3755 字）+ 界面用字，共 3769 字。
5. **硬件型号 / 协议名保留原文**：`IBM Gekko`、`SLOT-A`、`NTSC Revision 1.0`、FTP 指令等。
6. **设置页第 5、6 页按 Y 无帮助**：`tooltips_game[]` 用枚举值做下标初始化，但
   `get_tooltip()` 用页内序号索引，取到 NULL。原版即如此，与汉化无关。

## 五、自行构建

工具链：devkitPro + libogc2（MSYS2 环境）。

```bash
bash build-local.sh dev     # 全量构建
bash build-local.sh inc     # 增量构建（改一两个文件时，约 6 秒）
```

产物：`cube/swiss/swiss.dol`。

### 汉化维护流程

```bash
# 1. 改译文：编辑 translations/*.tsv（英文<TAB>中文，\n 表示换行）
# 2. 应用
python tools/apply_translations.py translations/settings.tsv
# 3. 预检（缺字 / 配置取值被翻译 / 字模不同步）
python tools/preflight.py
# 4. 构建并推送
bash build-local.sh inc && python tools/wiiload.py <IP> swiss.dol
```

### 工具一览

| 工具 | 用途 |
|---|---|
| `gen_font.py` | 由 `fonts/unifont.hex` 生成 `cjkfont.c/h`（16×16 点阵，分 8 页） |
| `check_glyphs.py` | 源码里用到的字符是否都在字模内（缺字会**整字不画**，不是豆腐块） |
| `check_config_arrays.py` | 拦截「翻译了 `swiss.ini` 取值」这类致命错误 |
| `preflight.py` | 上述检查串联，构建前必过 |
| `apply_translations.py` | 按映射表批量替换源码中的字符串 |
| `audit_widths.py` | 用实机导出的真实字宽，检查译文是否超出控件宽度 |
| `wiiload.py` | 推送 DOL 到实机（零依赖，替代 devkitPro 的 wiiload） |
| `grab_screen.py` / `pad.py` / `upload_file.py` | 抓图 / 远程按键 / 上传文件（需 DOL 内的诊断端点） |

字模参数：16×16 1bpp 位图，每页 512×256 I4（64KB），512 字/页，共 8 页；
运行时展开为 512KB 图集，按字绑页。

> 脚本里的目录是作者的固定结构（`..\swiss-gc`），移植到别处时改
> `gen_font.py` 的 `OUT_DIR`、`collect_from_source()` 的默认根目录，
> 以及 `audit_widths.py` / `make_release.py` 顶部的 `SRC` / `SWISS` 常量。
